# ahmedsabanovic.github.io

Personal academic website built with [al-folio](https://github.com/alshedivat/al-folio), a Jekyll theme for academics.

## Getting started

For installation and deployment details, refer to [INSTALL.md](INSTALL.md).

For customization details, refer to [CUSTOMIZE.md](CUSTOMIZE.md).

## Running locally

```bash
docker-compose up
```

Or with native Jekyll — see [INSTALL.md](INSTALL.md) for details.
